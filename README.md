# Pyramid Condenser · 金字塔原理文档精炼

用**金字塔原理**提炼长篇文件/内容的文档精炼 Skill。输入一份长文档，一次性输出**两种视角**的结果：一份给你自己看（高信息密度、可追溯），一份给领导/客户看（结论先行、面向决策）。

适用于报告、政策文件、技术文档、合同、会议纪要、行业资料等长篇内容，需要"精简、提炼、概括、浓缩、抓重点、输出结论"或"给领导/客户汇报"的场景。

## 核心能力

每次处理固定输出两大块，互不混淆：

| 模式 | 给谁看 | 特点 |
|---|---|---|
| **A · 个人精读版** | 你自己 | 信息密度高：内容地图、核心结论、关键证据链、MECE 结构化要点、疑点待核实、可复用素材 |
| **B · 汇报沟通版** | 领导 / 客户 | 结论先行、面向决策：一句话电梯陈述、中心论点→分论点金字塔、关键数据、建议与请求、一页纸摘要、可开口的汇报话术 |

## 用法

**1. 触发**：把长篇文件/内容发给 AI（Word、PDF、图片、网页、粘贴文本均可），并提出精简、提炼、总结、抓重点、或"给领导/客户汇报"等需求，本技能即自动启用。

**2. 处理流程**（4 步）：
1. 通读并吃透全文
2. 用金字塔四原则重组（结论先行 / 以上统下 / 归类分组 MECE / 逻辑递进）
3. 按两种模式分别组织内容
4. 自检后交付

**3. 输出**：默认同时给出模式A与模式B。也可只取其中一种，或对某板块单独展开（如"演讲"、"赞美与批评"）。

## 设计守则

- **只提炼、不臆造**：每个结论可追溯到原文；原文没有的推断明确标注"推断"。
- **矛盾信息不隐藏**：原文自相矛盾处，模式A 显式列出，模式B 按最可信口径处理并注明。
- **两种模式都输出**：缺一不可，且内容与表达方式明确区分。
- **反证不略过**：原文的反方观点与风险不隐藏，模式A 显式列反证，模式B 以"风险提示"附末。

## 适用 / 不适用

- ✅ 长篇文件、长报告、政策、合同、纪要、行业资料等需要提炼核心结论的材料。
- ❌ 单条短消息、无需提炼的简单问答。
