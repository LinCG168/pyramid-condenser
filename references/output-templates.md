# 两种模式的完整输出模板与示例

本文件规定每次输出**必须**遵循的书写模板。处理时先读本文件，再按模板动笔。

## 引言行（每次必写，3 句以内）

> 已对《材料名》完成金字塔提炼。下面分两种视角输出：**一、个人精读版**供您快速掌握全文与二次加工；**二、汇报沟通版**供您直接向领导/客户汇报。二者内容与详略不同，请按需取用。

---

## 模式A · 个人精读版（给用户自己看）

### 模板

```
## 一、个人精读版（您自己看）

**1. 内容地图**
一句话定位：这是一份【材料类型】，主题是【主题】，约【体量】。作者核心诉求是【诉求】。

**2. 核心结论（结论先行）**
- 结论一：一句话
- 结论二：一句话
- 结论三：一句话（通常 3~5 条）

**3. 关键证据链**
- 【结论一】的支撑：关键数据/事实/论据（尽量带原文出处或章节定位）
- 【结论二】的支撑：……
- （每条结论给出 1~3 条最硬证据）

**4. 结构化要点（MECE）**
按分类框架（时间/结构/程度/因果）归纳的完整要点，保留细节层：
- 分组一
  - 子项 1.1
  - 子项 1.2
- 分组二
  - 子项 2.1

**5. 疑点与待核实**
- 原文存疑处一：说明
- 矛盾/缺失处二：说明
- （没有则写"未发现明显疑点"）

**6. 可复用素材**
- 金句/关键表述：……
- 可直接引用的数字：……
```

### 示例片段

```
**1. 内容地图**
这是一份关于【新品上市方案】的内部评审报告，主题是是否Q3推新品，全文约8000字，作者的核心诉求是争取资源与排期。

**2. 核心结论（结论先行）**
- 新品值得Q3上市，但需压缩首波渠道投入。
- 竞品已先行，晚一个季度将丢失约15%的窗口红利。
- 当前供应链产能只能支撑预期的70%，需同步扩容。

**3. 关键证据链**
- 结论一支撑：文中测算首波ROI约1.8（第3章表2），但渠道投入占比过高。
- 结论二支撑：竞品X已于上月铺货，Q2数据环比+22%（第4章）。
- 结论三支撑：工厂当前月产能约5万台，需求预测8万台（第5章）。
```

## 模式B · 汇报沟通版（给领导/客户）

### 模板

```
## 二、汇报沟通版（给领导/客户）

**1. 一句话结论（电梯陈述）**
【建议做/不建议做 + 核心判断】。因为【最关键的一条理由】。

**2. 中心论点 → 分论点金字塔**
- 中心论点：……
  - 分论点1：……
    - 论据：……
  - 分论点2：……
    - 论据：……
  - 分论点3：……
    - 论据：……
  （3~7 个分论点；每个分论点 1~2 条最硬论据，最重要的放最前）

**3. 关键数据/事实**
- 数据1（带来源/口径）
- 数据2
- （只列汇报必须用到的，精炼）

**4. 建议与请求**
- 若需决策：给出 2~3 个选项 + 推荐项及理由
- 若需资源/批示：明确列出需对方做什么

**5. 一页纸摘要（金字塔图式）**
用缩进式金字塔把全文压缩成一屏：
- 中心论点
  - 分论点1 → 论据
  - 分论点2 → 论据
  - 分论点3 → 论据

**6. 汇报话术（可选，1~2 段可直接开口）**
一段可直接念的汇报稿，30~60 秒能讲完，含结论、关键依据、请求。
```

### 示例片段

```
**1. 一句话结论（电梯陈述）**
建议Q3上市新品，但首波渠道投入压缩三成、并同步扩容产能。因为竞品已先行，晚一个季度将丢失约15%的窗口红利，而当前产能只能支撑预期销量的70%。

**2. 中心论点 → 分论点金字塔**
- 中心论点：Q3上市新品是当前最优决策，需配套控投入、扩产能两项动作
  - 分论点1：市场窗口正在收窄
    - 论据：竞品X已铺货，Q2数据环比+22%
  - 分论点2：新品自身ROI达标
    - 论据：首波ROI测算约1.8，优于公司1.5的立项线
  - 分论点3：产能是当前唯一瓶颈
    - 论据：月产能5万台 vs 需求预测8万台
```

## 分层与字数建议

- **模式A**：核心结论 3~5 条；结构化要点可展开到子项；篇幅约为原材料的 15%~25%（长文）或 20%~30%（短文）。
- **模式B**：分论点 3~7 个；全篇力求在 1~2 分钟内讲完；篇幅约为原材料的 5%~10%，务必比模式A更精简。
- 若原材料很短（<1000字），两模式篇幅相应压缩，但**结构与两种视角的区分不能省**。

## 常见错误对照

| 错误 | 正确做法 |
|---|---|
| 只输出一种模式 | 两种模式都必须输出 |
| 模式B写成模式A的缩写 | 模式B要换表达：面向决策、结论先行、语言有力 |
| 编造原文没有的数据 | 无来源数字标"待核实"，推断标"推断" |
| 藏起反方观点/风险 | 模式A显式列反证；模式B以"风险提示"附末 |
| 结论先行落空（先铺垫后结论） | 中心论点必须在最前面 |
